# focus-isle
像素風專注冒險小島番茄鐘

# 1. 核心概念與目標
將傳統單調的番茄鐘工作法（25 分鐘專注、5 分鐘休息）遊戲化。使用者專注時，畫面中央的像素懸浮浮空島會隨時間動態生長植物、出現小動物與金幣；若中途中斷放棄，小島會遭遇暴風雨並枯萎，藉此強化專注動機。

# 2. 目標受眾與使用場景
- 需長時間自習、寫報告或編寫程式的學生與開發者。
- 喜愛復古像素遊戲（Pixel Art）與沉浸式氛圍音效的使用者。

# 3. 功能規格清單
### 3.1 核心計時引擎
- **工作模式（Focus）**：預設 25 分鐘（支援快速測試模式：10 秒）。
- **休息模式（Break）**：預設 5 分鐘。
- **長休模式（Long Break）**：每完成 4 次番茄鐘，自動進入 15 分鐘長休。
- **狀態控制**：開始（Start）、暫停（Pause）、放棄重置（Reset）。

### 3.2 像素冒險小島（HTML5 Canvas 渲染）
- **島嶼基底**：像素風格浮空島，帶有輕微上下浮動的呼吸動畫。
- **專注階段視覺成長**：
  - 0% ~ 25%：光禿草地，出現小嫩芽。
  - 25% ~ 50%：長成小樹苗，天空飄過白雲。
  - 50% ~ 75%：大樹開花，小島周圍出現像素蝴蝶／螢火蟲。
  - 75% ~ 100%：結滿金色果實，出現像素小島寵物（小倉鼠／小貓）。
- **失敗／中斷機制**：若在專注中按下「放棄」，天空變為灰暗暴風雨，樹木暫時枯萎凋零。

### 3.3 獎勵與經濟系統（LocalStorage 永續儲存）
- **專注幣（Coins）**：每完成 1 次專注獲得 25 金幣。
- **島嶼圖鑑商店**：
  - 解鎖櫻花樹外觀（需 50 幣）。
  - 解鎖夜晚星空模式（需 100 幣）。
- **歷史數據累計**：累計專注次數、累計專注分鐘數。

### 3.4 音效系統（Web Audio API 原生合成，零外部依賴）
- 按鈕點擊：8-bit 復古嗶聲（Square Wave）。
- 專注完成：8-bit 勝利升調三連音（Fanfare）。
- 放棄／失敗：8-bit 低沉降調警示音。

## 4. UI/UX 與視覺設計
- **色調計畫**：經典復古 Game Boy / 16-bit 暖綠與泥土褐色調，深色背景減少眼睛疲勞。
- **排版佈局**：單頁式儀表板（Single Page），RWD 手機與電腦螢幕皆能等比例自適應。
